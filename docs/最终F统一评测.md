## 查询配对 Bootstrap

以完整查询重采样 10,000 次、seed=20260930；同一抽样用于比较双方。分类指标基于抽中的全部商品对重新计算，nDCG@10 按查询平均。下面分类差值单位为百分点，nDCG 使用原始数值差；区间为单项 95% 区间，未作多重比较校正。

| 比较 | ΔAccuracy（pp） | ΔMacro-F1（pp） | ΔnDCG@10 |
|---|---|---|---|
| FUSION_KD − CE_CONT | −0.15 [−0.92, +0.61] | +0.91 [+0.11, +1.74] | +0.0040 [−0.0010, +0.0091] |
| FUSION_KD − REF_KD | +0.09 [−0.35, +0.52] | +1.04 [+0.40, +1.73] | +0.0027 [−0.0014, +0.0069] |
| FUSION_KD − S | +0.90 [+0.24, +1.56] | +1.72 [+0.79, +2.72] | +0.0016 [−0.0044, +0.0077] |

F 上的 Macro-F1 比较支持融合监督改善了独立学生。相对两个训练对照，Accuracy 与 nDCG@10 区间均跨零，表示证据不足，不能解释为等效、非劣或证明没有变化。

## 选择规则与结论范围

三组仅在 tune 上选点，选点冻结后再评测其他划分。选中步数分别为 569 / 569 / 488，预算均为 650；选中模型曝光不同，不能称为等曝光比较。

训练只有一个 seed，查询 Bootstrap 不涵盖重新训练的方差。F 此前已被多次查看，属于既有固定评测集，不是新独立测试。另一既有划分 gate 上，FUSION_KD − REF_KD 的 Macro-F1 为 +0.76pp [−0.06, +1.56]，证据不足；完整结果一并保留。

旧门控实验的 A2 / TA2 / G2 数字保留在 [历史报告](../results/final/RESULT.md)，其查询 Bootstrap 为 2,000 次。旧报告不能作为本轮结果，也不替代本次统一重评的 S / S_C50 数字。
