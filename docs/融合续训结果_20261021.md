## 成本口径：谁实际花得多

三组都是跑到 650 步预算耗尽才停，选点只是"事后挑哪一个存档"，不改变已经付掉的算力。

| 项目 | CE_CONT | REF_KD | FUSION_KD |
|---|---|---|---|
| optimizer updates | 650 | 650 | 650 |
| 训练行曝光（预算内实付） | 20,796 | 20,796 | 20,796 |
| 训练墙钟（含 9 个 tune 评测点） | 2,264 s | 2,299 s | 2,334 s |
| 每步耗时 | 3.48 s | 3.54 s | 3.59 s |
| 选中 checkpoint 时的行曝光 | 18,206 | 18,206 | 15,614 |
| p_S 前向（10,398 行，本地 GPU） | 无 | 约 2.5 GPU 分钟 | 同 REF_KD，共享 |
| 教师 p_T | 无 | 无 | 5,195 条路由有效行 |

结论分三层，不要混用：

1. **三组实际训练更新数相同**：各 650 步、20,796 条次。训练墙钟约有 3% 差异，不能据此断言总算力成本严格相同，也不能说融合组因为较早选点而实际少训练。
2. **按选中 checkpoint 看数据量，FUSION_KD 少看 2,592 行（−14.2%）**。这是本次在更早评估点选到最佳 checkpoint 的观察，不能仅凭这一点证明更高样本效率或实际成本优势。
3. **按全成本看，FUSION_KD 是唯一有外部监督成本的组**：它是三组里唯一需要教师输出的。本轮边际为 0（缓存来自更早轮次），但若要把这份成本记在它头上，按历史台账折算（`results/final/manifest.json`：10,459 次请求、上界 ¥3.434274，输入 2 / 输出 8 元每百万 token 的保守费率）约 ¥0.000328/请求，则路由用到的 5,195 行约 ¥1.71 上界，整份 10,398 行缓存约 ¥3.41 上界。这是代理折算，不是当轮真实账单。

所以同预算比较成立、同总成本比较不成立。教师那份支出是一次性资产，下一轮仍是 0 新增，但把它说成"和 CE 一样便宜"是不诚实的。

另外，若问的是**部署推理**成本：C50 系统对低置信度商品对要跑 S + 教师两次前向；学生只跑一次。本轮的收益方向正是把双模型成本压进单模型，但如结果所示只走了差距的约 38%。

## 按预注册规则判定

方案里"成功"的写法是：融合学生相对 CE、REF_KD、起始 S 有一致实际收益，例如 Macro-F1 三个差值区间均为正、accuracy 无明确退化。

- F 上 Macro-F1 三个区间全部严格为正（+0.91 / +1.04 / +1.72）。三个比较方向一致，证据仍限于本次固定模型与评测数据。
- F 上 accuracy 最低的一项是相对 CE_CONT 的 −0.15pp，区间跨零；相对 REF_KD +0.09pp 跨零；相对 S +0.90pp 严格为正。没有可检测的退化。
- F 上 nDCG@10 三个区间全部跨零：这一轮排序质量差异的证据不足，不能据此断言没有提升或退化。
- 关键分离项 FUSION−REF_KD 在 F 上 +1.04pp、区间 [+0.40,+1.73] 不含零，**支持"教师互补信息确实带来增量"这一解释，而不是仅靠原模型软目标约束**。但 gate 上同一项 +0.76pp、区间 [−0.06,+1.56] 跨零，属于边缘。两个拆分方向一致但强度不同，应表述为"F 上支持、gate 上未达可判定"，不要合并成单一断言。

因此按方案口径，F 上达到预定的 Macro-F1 正向区间条件。Accuracy 未检出明确退化，但这不是非劣证明；nDCG 差异证据不足，不能称为无变化。结论仍受限于单 seed、F 已被反复查看。

## 必须一起说的限制

1. **没有追上融合系统本身**。同一新 S 推理上的 S_C50 参考是 Macro-F1 52.08、nDCG@10 0.7804，FUSION_KD 是 49.22 / 0.7698。学生相对初始 S 涨了 1.72pp，但距 C50 仍差 2.86pp。按算术比值，本轮只走了 (49.22−47.50)/(52.08−47.50)≈38% 的差距，这是描述性比值，不是效应估计。
2. **曝光不等**。FUSION_KD 在 488 步选点（15,614 行），两个对照在 569 步（18,206 行）。比较的是相同预算上限与相同选点规则，不是等曝光。
3. **单 seed**。bt 区间只涵盖查询抽样，不含训练随机性；多指标不是独立重复验证。
4. **F 是已查看过的固定评测集**，已反复查看，不能包装成新的独立测试集；tune 数字是选点结果，不是留出证据。
5. 只能否定/支持"本配方、本预算、本初始化、本 loss"下的迁移效果；不能推广到其他蒸馏方式，也不能推翻既有推理互补结论。
6. 相对 S 的提升同时包含"续训本身带来的增益"（CE_CONT 也 +0.81pp Macro-F1），两个本轮训练对照分别给出相对 CE_CONT 的 +0.91pp 与相对 REF_KD 的 +1.04pp；前者比较整套配方，后者在相同软监督控制下比较目标来源。
