# 当前训练流程：固定融合目标的三组续训

更新：2026-10-22。已完成实验的数字保持不变；唯一入口为 [train.py](../src/train.py)，配置为 [fusion_continue_20261021.json](../configs/fusion_continue_20261021.json)。模型是 Qwen3-0.6B + LoRA；本轮三组均从已有 S adapter 续训。

## 模型角色与数据流

1. **原模型 S**：此前在 20,941 条 ESCI 样本上完成 SFT，提供冻结概率 p_S，也提供三组共同的初始 adapter。
2. **已有 DeepSeek 教师**：提供冻结缓存 p_T，不参加本轮参数更新，不发送新 API 请求。
3. **三组新学生**：各自复制同一 S adapter，重置优化器和 RNG；训练时更新 LoRA 参数。
4. **CE_CONT**：只接受真实标签，是本轮独立训练对照，其输出不会反过来构造其他组的监督。

本轮参数更新只使用 `data/posttraining/train.jsonl`：10,398 条、512 查询。此前训练 S 的另外 20,941 条不在本轮任何一组中再次使用。历史中“从官方底座和未训练 LoRA 直接训练”的方案属于其他轮次，不是本轮的实际执行方式。

## 固定监督与损失

路由仅依据原 S 在训练样本上的 `max(p_S)`，从低到高取一半；并列时按固定哈希排序。5,199 条被选中，其中 5,195 条有有效教师概率。

```text
q = (p_S + p_T) / 2    路由选中且教师缓存有效
q = p_S                其余样本
```

全部 10,398 条都有 q。目标在训练前固定，不依据真实标签、教师是否答对或新学生置信度更新。

| 组 | 损失 | 作用 |
|---|---|---|
| CE_CONT | CE(y,p) | 真实标签续训 |
| REF_KD | (CE(y,p) + KL(p_S ∥ p)) / 2 | 原模型软监督对照 |
| FUSION_KD | (CE(y,p) + KL(q ∥ p)) / 2 | 融合输出蒸馏 |

温度与软监督系数均为 1；KL 先对类别求和，再按实际 batch 行数平均。两个软监督组都覆盖全部样本；融合组不再叠加另一个 S KL。实际损失位于 [fusion.py](../src/fusion.py) 的 `loss_rows()`。

FUSION_KD − CE_CONT 检验整套融合蒸馏配方相对标签续训的收益；FUSION_KD − REF_KD 在相同软监督覆盖、系数和归一化下，检验把原模型目标换成固定融合目标的增量。第二项不要求声称原模型 S 比其初始化副本“更强”。

## 训练控制与实际选点

| 项目 | 本轮设置 |
|---|---|
| 初始化 | 同一 S adapter；每组独立重置 AdamW / RNG |
| seed / dropout | 20261001 / 0 |
| effective / micro batch | 32 / 4，尾批 30 条按实际数量归一 |
| 学习率 | 33 步 warmup 至 2e-5，再 cosine 至 2e-6 |
| 预算 | 每组最多 650 updates / 2 epochs |
| tune 评测 | 0、82、163、244、325、407、488、569、650 |
| 选点 | tune Macro-F1 最高；精确并列看 nDCG@10，再选更早步 |
| 早停 | 至少 325 步，连续 4 次评测未达到累计 0.001 Macro-F1 改善 |

三组实际都跑满 650 步，未触发早停。CE_CONT / REF_KD 各选 569 步、18,206 条次；FUSION_KD 选 488 步、15,614 条次。实际每组总训练曝光为 20,796 条次。共同预算上限和共同选点规则不等于选中模型的曝光量相等。

三组选点冻结后才评测其他划分。F 不用于本轮 checkpoint 或超参数选择；它此前已经在项目中被查看过，不称为新的独立测试。

## 当前结果

F 上 CE_CONT / REF_KD / FUSION_KD 的 Accuracy 分别为 55.88% / 55.65% / 55.73%，Macro-F1 分别为 48.31% / 48.18% / 49.22%。

融合学生相对两个训练对照的 Macro-F1 分别提高 0.91pp [0.11, 1.74]、1.04pp [0.40, 1.73]；相对本轮重评的 S 提高 1.72pp [0.79, 2.72]。这些结果来自学生独立推理。完整结果和限制见 [实验报告](../results/fusion_continue_20261021/RESULT.md)。

代码与运行见 [目录与复现说明](目录与复现说明.md)、[训练与评测](训练与评测.md)。本地原始输出位于 `runs/fusion_continue_20261021/`；公开汇总位于 `results/fusion_continue_20261021/`。

## 两段入口与文件清单

```bash
python src/train.py sft --check-only
python src/train.py sft --output runs/sft_new
python src/train.py fusion --preflight
python src/train.py fusion --train --evaluate --output runs/fusion_new
```

第一阶段从官方底座创建 LoRA：seed=20260928，2 epochs，20,941 条 / 1,024 查询，group_size=2，groups_per_update=16，micro_groups=1，lr=1e-4，warmup=5%，max_length=512；输出到 `runs/sft_new/models/S`。第二阶段仍加载固定的 `models/S`，不会自动换成新训练的 S。
