## 已发布结果

[融合续训报告](../results/fusion_continue_20261021/RESULT.md)与[report.json](../results/fusion_continue_20261021/report.json)是验收依据：F 含 512 查询 / 10,459 商品对；FUSION_KD Accuracy / Macro-F1 为 55.73% / 49.22%，相对 CE_CONT / REF_KD 的 Macro-F1 为 +0.91 / +1.04 个百分点，两项查询配对 95% 区间均为正。
