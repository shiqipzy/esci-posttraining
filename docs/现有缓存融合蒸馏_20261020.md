# 融合蒸馏：只用 10,398 条，逐条具备软监督

更新：2026-10-20，按用户纠正收窄数据范围。**当前只修正实验合同，尚未启动新训练。**

## 固定的数据范围

三组训练都只使用 `data/posttraining/train.jsonl`：10,398 条 / 512 查询。每轮完整使用这一集合，重复训练复用缓存。

**另外 20,941 条不混入本轮训练，也不作为额外 CE 数据。** 撤回上一版“31,339 条训练、仅其中 10,398 条蒸馏”的混合方案。本轮选择用户明确允许的“只跑这 10,398 条”。如果以后切换全量，必须为全量生成对应本地模型概率及所需教师目标，另冻结完整覆盖的实验，不能沿用本轮部分覆盖方案。

半量融合系统对每条样本都有输出概率：一半样本融合本地模型和教师，另一半输出本地模型概率。**蒸馏学习的是整个系统的输出，因此全部 10,398 条都计算软监督损失**，不把后半样本的蒸馏权重置零。半量描述教师参与的路由预算，不是蒸馏覆盖率。

## 模型身份不能替换

前一版自动采用了历史 `models/S` 的概率，又将对照改成“S 蒸馏”。这两项均撤回；不从旧 S 初始化，不引入 S 蒸馏组，也不把历史 S 概率当作新模型概率。

若融合来源采用最近直训的 CE 模型，应取该模型在 tune 上选出的 checkpoint，并生成它在全部 10,398 条上的概率。最近子集轮的 CE 选中步为 488，adapter 哈希为 `6bbc352e13c24fc05d451433aeb252aa299914415789b26ef906b14fd7c09d43`。本地回传目录里已有 tune/gate/F 预测，没有这 10,398 条训练预测；权重也没有回传。因此这一数据准备步骤尚未完成，不能用历史 S 文件替代。

生成本地模型概率不涉及 DeepSeek API。旧教师缓存覆盖这 10,398 条，其中 10,387 条有效、11 条失败；可复用，训练轮数增加不会消耗缓存。

之前生成的 `runs/fusion_targets_20261020/targets.jsonl` 是**历史 S 的候选产物，已撤回作为当前训练输入**，保留供核查。其 5,195 条实际融合等统计只适用于历史 S 路由；更换本地模型后必须重算路由，不能沿用这些计数。

## 三组保持 CE / KD / WCE

不再自行换成带 S 蒸馏的三组。三组均从同一官方底座、同一份未训练 LoRA 开始，训练数据相同，不从旧 S 或先前训练的 checkpoint 续训。

设 `p_local` 为明确选定并冻结的本地模型概率，`p_T` 为已有教师概率。按 `max(p_local)` 从低到高选 5,199 条，沿用既有稳定平局规则；不以标签或教师答对与否选择。

```text
q = (p_local + p_T) / 2   路由选中且教师缓存有效
q = p_local              未选中或教师缓存失败
```

| 组 | 全部 10,398 条上的逐样本损失 | 软监督覆盖 |
|---|---|---|
| CE | `CE(y,p)` | 硬标签基线 |
| KD（融合蒸馏） | `CE(y,p) + λ*KL(q||p)` | 10,398 / 10,398 |
| WCE | `(1+λ)*CE(y,p)` | 硬标签权重对照 |

KD 的 λ 在每条训练样本上相同，不乘旧教师正确性 mask，也不乘半量路由 mask；无缓存教师的样本仍有本地模型提供的系统输出 q。WCE 同样在全部样本上匹配额外系数。每批按实际样本数归一化。融合 KD 中没有独立的旧 S KL。

这三组检验“蒸馏融合系统是否帮助单模型”，不单独分解融合系统中本地模型与教师各贡献多少。不能把无法区分的机制写成已经证明，也不为此擅自增加实验组。
