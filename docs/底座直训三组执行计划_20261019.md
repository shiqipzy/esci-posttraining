## 研究问题与三个实验组

研究问题改为：从同一个 Qwen3-0.6B 底座出发，在相同训练数据、参数化、预算和选点规则下，教师正确性门控的软概率监督能否改善 ESCI SFT？

三个实验组均直接从官方底座及同一份未训练 LoRA 参数开始，没有先行的公共任务 SFT。

| 名称 | 逐样本损失 | 作用 |
|---|---|---|
| CE | `CE(y,p)` | 普通标签 SFT 基线 |
| KD | `CE(y,p) + c*m*KL(t||p)` | 教师正确性门控的软概率监督 |
| WCE | `CE(y,p) + c*m*CE(y,p)` | 在相同样本上加强真实标签监督，控制选样与额外监督权重 |

`m` 只在有教师缓存、概率有效且教师 argmax 等于训练标签时为 1，其余为 0；`c=10387/5467`，沿用缓存子集上的权重定义，温度为 1。全部损失按实际 batch 样本数取平均；尾批不能按完整 batch 归一化。

三组均去掉旧目标中的 `KL(p_S||p)`，也不替换成到未微调底座的 KL。旧项用于保留已适配 S 的任务行为，在新设计中没有同样的依据。KD 的教师 KL 仍保留，它是实验所考察的监督信号。

KD−CE 检验门控教师监督整体是否有收益；KD−WCE 检验使用软目标相对同样本硬标签加权的增量作用。WCE 使用教师正确性选样，因此不是完全不依赖教师的基线。三组不能单独证明正确性门控优于不门控，也不能证明收益只是某种抽象“知识传递”机制。

旧 A2/TA2/G2 的结果不能改名成为这三个实验组的结果。新结论是“不同监督目标的直接 SFT 对照”；旧结论是“已适配学生上的续训对照”，两种设计回答不同问题。

## 相同起点与训练预算

以下是新运行前要冻结的初始配方，不是保证充分优化的超参数。原来的 lr=2e-5、650 步用于已适配 S 的续训，不直接搬到本实验。

| 项目 | 三组共同配置 |
|---|---|
| 底座 | `models/base`，按 `configs/models.lock.json` 校验 |
| 可训练参数 | LoRA r=16、alpha=32、dropout=0.05；q/k/v/o、gate/up/down；底座冻结 |
| 初始化 | seed=20260928；生成并保存一次未训练 LoRA，三组分别加载相同文件；它不是 SFT checkpoint |
| 样本顺序 | 按固定顺序拼接两份文件后洗牌；每轮 seed=20260928+轮次索引；三组完全一致 |
| batch | effective batch=32，microbatch=16；每轮 980 步，末批 11 条 |
| 优化器 | 各组独立初始化 AdamW，峰值 lr=1e-4，weight_decay=0.01，clip=1.0 |
| 上限与调度 | 最少 2、最多 6 轮；按固定上限 5,880 步定义调度，warmup 294 步，随后 cosine 至峰值的 10% |
| 精度与输入 | CUDA BF16，FP32 损失，max_length=512，eval batch=8，gradient checkpointing 开启 |
| 评估位置 | 第 0 步及每轮第 490、980 步；每次评估整个 tune，保留逐样本预测 |

三组的随机种子、dropout 设置、样本顺序和优化器/调度参数都相同。共享初始化文件哈希；不能只看底座文件一致而忽略 LoRA 初始参数不同。独立 optimizer 状态、随机数状态及更新日志必须分组保存。

microbatch 只影响梯度累积粒度，不改变 effective batch，也不改变“损失按实际样本数取平均”的归一化方式。实测 RTX 4080 SUPER 在 microbatch=4 时 GPU 利用率约 15%（约 3.4 秒/步），microbatch=16 时约 0.9 秒/步；默认配方取 16，三组完全一致。

取消公共 S 不保证更省计算：现在三组分别学习全部任务数据。最坏情况每组 5,880 步，共 17,640 步；它与旧方案的更新数、数据曝光和学习率都不同，不能拿旧新差值当作单因素消融。

## 训练停止与 checkpoint 选择

不再需要 S 的质量准入门槛。之前提出的 50% Macro-F1、55% accuracy 等不是本实验的停训条件，也不是判定项目有没有价值的界线。底座过线可能说明目标偏低，应结合任务要求重新标定；不能只凭过线认定训练无意义。

保留学习曲线检查，避免只因固定预算用完就宣称训练充分：

1. 三组在相同评估位置检查，至少训练 2 轮。每组分别计算最近 4 个评估点的最大 accuracy、Macro-F1，相对于窗口开始前各指标的历史最好值，两个增益都严格小于 0.005 时，记为达到操作性平台。第 0 步基线用于建立初始历史。
2. 只有三个实验组在同一评估位置都满足平台条件，才共同提前结束。不得某组单独早停、另一组继续增加训练预算。可轮流训练到下一个评估位置；切换时必须保存并恢复全部 optimizer/scheduler/RNG 状态，不能重启优化器模拟无损续训。
3. 各组从共同执行过的评估位置中按同一规则选 checkpoint：tune Macro-F1 最高 → 精确并列时 nDCG@10 最高 → 再取较早步数。所选步数可以不同，但三组获得的训练和搜索预算相同；同时报告共同停止点的三组结果，供核对选点影响。
4. 如果到 6 轮仍有实验组没有达到平台，记录 `budget_exhausted` 及各组状态。这仍是一个有效的固定预算比较，但不支持“各组已充分收敛”的说法。
5. 保存 train loss、tune NLL、accuracy、Macro-F1、每类指标和 nDCG@10。平台伴随严重过拟合或类别塌缩时必须解释；不能凭曲线变平称基线已充分优化。
6. 项目所有者可直接停止训练：当 tune Macro-F1 已从峰值持续下降（过拟合）时，允许在任一已完成评估位置后停止，不再等待共同平台。停止后仍按第 3 条同一规则在已评估位置中选 checkpoint（通常是峰值点），并在学习曲线、选点文件和报告中如实记录停止位置。

平台规则是开发停止规则，不是统计上证明继续训练无收益。固定单一超参数配方得到的 CE，也不能称为所有可能配方中的最强基线。

## 评测与结论

固定模型后再评估 gate 和 F；这两个集合不用于选 checkpoint、调权重或延长训练。两者都已有历史使用，报告为既有集合上的开发检查/固定 F 比较，不能改称新独立测试。

基本对象为 B0（未微调底座）、CE、KD、WCE、T（缓存教师）。B0 用相同输入和四标签评分，作为任务适配参照，不能代替 CE/WCE 方法对照。零初始化 LoRA 作为 B0 推理路径时，须先确认与无 adapter 底座输出等价。

保留原项目的系统融合问题：对 CE 和 KD 分别计算 C50 和 Full 等权融合；C50 根据各自新预测选择 5,230 条，重新生成路由，不复用历史 mask。教师缺失时回退相应学生；T 单独将缺失计弃答。这样完整 F 报告包含 B0、CE、KD、WCE、T、CE_C50、CE_Full、KD_C50、KD_Full 共 9 个对象。

对所有对象并列报告 accuracy 与 Macro-F1，附每类 precision/recall/F1、混淆矩阵、NLL（教师缺失须单独说明分母）和 nDCG@10。NLL 的概率截断及统计口径在实现时固定并记录。

预先固定以下差值：KD−CE、KD−WCE、WCE−CE；三个训练组各自减 B0；KD−T；CE_C50−CE、CE_C50−T、KD_C50−KD、KD_C50−T；CE_Full−CE_C50、KD_Full−KD_C50。每项采用完整查询配对 bootstrap，2,000 次，seed=20260930，报告两项分类指标各自的点估计、差值及 95% 区间。

以上未校正区间用于完整展示，不能在多个比较中择优包装成整体确认性结论。至少明确区分：仅点估计改善、固定模型下有统计证据、跨训练 seed 稳定。本轮只做一个 seed，不承诺最后一项。

解释结果时：

- KD 优于 CE、但未优于 WCE：门控额外监督可能有用，尚未确认软目标的额外价值。
- KD 对 CE/WCE 均有收益：支持在本配方下软监督带来增益；仍须分别说明 accuracy、Macro-F1 的幅度和区间。
- 无明确收益：报告没有证据支持该方法在本配方下改善 SFT，不靠调整测试集、门槛或追加种子凑结论。
